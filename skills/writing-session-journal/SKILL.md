# セッションジャーナル執筆

## Overview

このリポジトリの記録系の心臓部。**会話で得た知見は揮発する前に git に固定する**（メモリ機能は使わない方針のため、ジャーナルが唯一の長期記憶）。1 セッション = `docs/journal/YYYY-MM-DD.md` への記録 + CLAUDE.md 同期 + commit までで 1 単位。

## 手順

1. **既存確認**: `docs/journal/<今日>.md` が既にあれば**追補 N** セクションとして追記（上書きしない）。無ければ新規作成
2. **本文執筆**: テンプレは `skills/claude-md-diet/templates/journal-template.md`。必須セクション:
   - ヘッダ引用（セッション時間帯 / 作業者 / モデル名）
   - サマリー（2-4 行）→ 主要イベント（時系列）→ 完了した作業（チェックリスト）→ **学んだこと / 気づき**（番号付き）→ **未完了 / 持ち越し** → 関連ファイル → タグ
3. **知見のルーティング**（ジャーナルに書くだけで終わらせない）:
   | 知見の種類 | 行き先 |
   |---|---|
   | 操作ルール・教訓の昇格 | docs/rules/*.md |
   | マシン固有の変更 | docs/machines/<hostname>.md |
   | プロジェクト進捗 | docs/projects/<name>.md |
   | しぶ観察・ミニマリスト系 | takeru-chatbot/knowledge/ |
   | 期限が生まれた | docs/reminders.md |
4. **CLAUDE.md 同期**:
   - 「最近 2 週間」の先頭に今日の 1 行サマリー（日付・曜日・太字見出し＋圧縮本文＋ジャーナルリンク）を追加
   - 2 週間より古くなった行は `docs/archive/YYYY-MM/index.md` へ移動（**移動 ≠ 削除**）
   - 「現在の状態」「今週の優先 TODO」に影響があれば更新
5. **commit**: 日本語メッセージ。形式は「<要約>: <主要成果を読点区切りで>」。`git push` まで（origin は公開リポ＝個人情報注意）

## 書き方の規律

- **推測と事実を分ける**: 確認していないことは「（推測）」「要確認」と明記。後で誤りと判明したら、**元の記述を消さずに「⚠️ 訂正注記 (日付)」を追記**する（5/6 追補 9 E-2 方式。記録の改竄をしない）
- **時刻は JST 明記**。ログの `Z` は UTC（`21:21Z = 06:21 JST`、6/2 の誤判定教訓）
- **数字を残す**: バージョン・サイズ・件数・所要時間・金額。後から検証可能になる
- **ユーザーの言葉は鉤括弧で原文引用**（判断の根拠として残す）

## Common Mistakes

| ミス | 対処 |
|---|---|
| ジャーナルだけ書いて CLAUDE.md 同期を忘れる | 手順 4 は必須。次セッションの起点が腐る |
| 同日 2 回目で新ファイルを作る | 追補 N セクションで追記 |
| 「完了しました」だけ書いて検証結果を書かない | exit code・出力・確認方法まで記録 |
| 古い行を CLAUDE.md から黙って消す | archive index へ移動してから消す |
