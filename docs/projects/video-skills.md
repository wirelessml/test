# 動画スキル向上プラン

作成日: 2026-06-06

## 目的

当面の最優先は、収益や採算ではなく、仲啓輔の動画制作スキルそのものを上げること。

Bグループ/Minimalist Takeru 関連の業務委託案件は、採算判断の対象ではなく、実戦に近い練習テーマとして使う。目標は「訪問取材・ルームツアー型YouTubeを、自分で企画、撮影、編集、サムネ作成、投稿まで一通り回せる状態」に近づけること。

## 暫定フォーカス

主軸は次の2つに置く。

1. 撮影: iPhoneで現場を見やすく、聞きやすく、安心して見られる映像にする力
2. GUI手編集: DaVinci Resolve/CapCut等のタイムラインで、テンポ、間、テロップ、音量、色を手で整える力

理由:

- AI/自動化、文字起こし、ffmpegベースの後工程は既に強い。
- 未検証の最大領域は、現場の撮影と、GUI編集の手ざわり。
- 40〜60代女性視聴者が多いミニマリスト/生活系動画では、派手さより「見やすさ、聞きやすさ、生活の再現性、安心感」が重要。

## 成果物

最初の到達点は、2週間で以下を1本完成させること。

- 題材: 自宅または身近な場所の「ミニマリスト視点ルームツアー」
- 尺: まずは8〜12分。余力があれば20分版も作る。
- 構成: 導入、部屋全体、収納/持ち物、考え方、まとめ
- 編集: GUI NLEで手編集する
- サムネ: 3案作る
- タイトル: 5案作る
- 公開: YouTube限定公開、またはローカル納品物として保存

## 制約と使い分け

| 環境 | 役割 |
|---|---|
| Mac M1 8GB | Claude用の司令塔。重い動画処理は避ける。台本、構成、軽い確認向け。 |
| masup / WSL2 | Codex用。ドキュメント、CLI、軽いffmpeg、分析向け。重い編集は避ける。 |
| しゅん先生PC | DaVinci Resolveなど重いGUI編集、書き出し、GPU処理の逃がし先。 |
| iPhone 15 Pro | 主カメラ。露出ロック、グリッド、自然光、外部マイク確認を徹底。 |

## 2週間スプリント

### Day 1: 基準作り

- iPhone設定を確認する。
  - グリッドON
  - 4K/30fpsまたは1080p/30fpsに固定
  - 手ぶれを抑える持ち方を決める
  - 露出/フォーカスロックを練習
- 1分のテスト動画を3本撮る。
  - 正面語り
  - 部屋全体の引き
  - 収納や持ち物の寄り
- 音声を確認する。
  - 声が小さい
  - 反響が強い
  - 冷蔵庫/換気扇/外音が邪魔
  - 服擦れや手持ちノイズがある

完了条件: 「この撮り方なら見られる」という基本設定を1つ決める。

### Day 2: ショット練習

同じ場所で、次の10ショットを撮る。

1. 部屋全体の引き
2. 入口から見た導線
3. 机/作業環境
4. 収納の開閉
5. よく使う持ち物3点
6. 捨てた物/持たない物の説明
7. 手元アップ
8. Before/Afterが分かる比較
9. 窓際や自然光のカット
10. まとめの正面語り

完了条件: 使えるBロールを最低10本確保する。

### Day 3: 構成と台本

8〜12分動画の構成を作る。

推奨構成:

1. 0:00-0:20 何が見られる動画か
2. 0:20-1:30 部屋全体と生活の前提
3. 1:30-4:00 収納/持ち物の具体例
4. 4:00-7:00 捨てた物、買わない物、続いている習慣
5. 7:00-9:30 視聴者が真似できるポイント
6. 9:30-10:00 まとめ

完了条件: 撮影前に「この順で撮る」と言える1枚構成にする。

### Day 4-5: 本番撮影

- 正面語りを最初に撮る。
- その後、Bロールを撮る。
- 同じ説明を角度違いで2回撮る。
- 失敗しても止めすぎず、編集で切る前提で進める。
- 個人情報、住所、郵便物、画面通知、家族情報が映っていないか確認する。

完了条件: 30分以上の素材を確保する。

### Day 6-7: GUI手編集1回目

DaVinci Resolve、CapCut、または使えるGUI NLEで編集する。

手編集の重点:

- 冒頭15秒で内容が分かる
- 無音、迷い、言い直しを切る
- Bロールを説明の上にかぶせる
- 音量を均一にする
- テロップは出しすぎない
- 文字は大きめ、白/黒縁で読みやすくする

完了条件: 8〜12分の粗編集を書き出す。

### Week 2: 仕上げと公開準備

- Day 8: 粗編集を見返し、退屈な箇所を10個メモする
- Day 9: カット詰め、Bロール追加、音量調整
- Day 10: 色と明るさを整える。暗い、黄色い、青いを放置しない
- Day 11: サムネ3案、タイトル5案を作る
- Day 12: 説明文、章立て、SNS投稿文を作る
- Day 13: 最終書き出し
- Day 14: 限定公開またはローカル保存し、振り返りを書く

完了条件: 1本を最後まで完成させる。

## 毎日の短時間ドリル

### 撮影15分

- 露出ロックして撮る
- 同じ物を引き/寄り/斜めで撮る
- 10秒静止してから動く
- 手ブレが出た理由を1つメモする

### 編集30分

- 1分素材を30秒にする
- 30秒素材を15秒にする
- 同じ素材で「落ち着いた版」と「テンポ速い版」を作る
- 音量だけを整える練習をする

### サムネ15分

- 1テーマで3案作る
- 文字は最大7〜10字
- 40〜60代女性が不安なく押せる表現にする
- 煽りすぎない

## 評価基準

毎回、5段階で自己採点する。

| 領域 | 見る点 |
|---|---|
| 撮影 | 水平、明るさ、手ブレ、見せたい物が分かるか |
| 音声 | 声量、反響、ノイズ、聞き疲れしないか |
| 構成 | 冒頭で目的が分かるか、話が迷子にならないか |
| 編集 | 間延び、不要な言い直し、Bロール不足がないか |
| テロップ | 大きさ、読みやすさ、出しすぎていないか |
| サムネ | 3秒で内容が伝わるか、安心感があるか |
| タイトル | 具体性、視聴者メリット、誇張の少なさ |

合格ライン:

- 初回は平均3でよい。
- 2本目で平均3.5を狙う。
- 4本目で「他人に見せても説明できる品質」を狙う。

## Bグループ案件を練習に転用する方法

本番案件に入る前に、以下を自分で模擬実施する。

### 取材前チェック

- 出演者に何を聞くか
- 撮ってよい場所、撮ってはいけない場所
- 住所、顔、家族写真、郵便物、PC画面の映り込み
- 片付け前提にしすぎない
- 視聴者が真似できるポイント

### 取材質問テンプレ

1. いつからミニマルな暮らしを始めたか
2. 何を減らして一番楽になったか
3. 逆に残してよかった物は何か
4. 収納で一番工夫している場所はどこか
5. お金、時間、家事で変わったことは何か
6. 40〜60代視聴者が今日から真似できることは何か
7. 失敗した捨て方、後悔した物はあるか
8. 今後も減らしたい物は何か

### 撮影ショットテンプレ

- 外観や住所が分からない導入カット
- 玄関/入口の導線
- 部屋全体
- 収納の中
- 毎日使う物
- あえて持たない物
- 生活感が伝わる手元
- インタビュー中の相槌/リアクション
- 片付けや動作の実演
- まとめの正面/斜めカット

## 既存自動化との接続

`takeru-video-editor` や既存の ffmpeg/文字起こし資産は、最初から全自動に寄せすぎない。

推奨ワークフロー:

1. iPhoneで撮る
2. 文字起こしする
3. AIで構成案とカット候補を作る
4. GUI NLEで人間が手で仕上げる
5. ffmpegは最終変換や軽い一括処理に使う

目的は、AIに任せることではなく、AIの下書きを見て自分の編集判断を鍛えること。

## 記録フォーマット

各練習後、以下を追記する。

```text
日付:
題材:
撮影時間:
編集時間:
完成尺:
一番良かった点:
一番悪かった点:
次に直す点:
自己採点:
```

## 次の具体アクション

1. iPhoneで「部屋全体」「収納」「正面語り」を各30秒撮る。
2. その3本を1分にまとめる。
3. GUI NLEで手編集する。DaVinciが重ければCapCutでよい。
4. 完成した1分版を見て、撮影/音声/編集の問題を10個書く。
5. その問題を直して、8〜12分版の本番撮影に入る。

- Codex: プラン、チェックリスト、構成案、台本、サムネ案、タイトル案、振り返り表を管理する。
- Claude Code on Mac: Gmail返信、ブラウザ操作、Mac側の素材確認、軽いGUI作業の補助。
- しゅん先生PC: DaVinci Resolveや重い書き出しが必要な場合の実行環境。

まずは「完璧な1本」ではなく、「最後まで完成した1本」を優先する。
