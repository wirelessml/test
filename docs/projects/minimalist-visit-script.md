# ミニマリスト宅訪問動画 脚本（1本完結版・テンプレート v1）

> 出典: masup Codex 制作メモ `minimalist-visit-production.md` ＋ 引き継ぎ書（`handoff-2026-06-06-video-production-codex-to-claude.md`）
> 作成: 2026-06-06 / Mac Claude Code
> 形式: **1本完結・25〜35分**。`〇〇`＝出演者（訪問ごとに差し替え）、`MC`＝仲（撮影・進行）。
> ⚠️ これは **完成動画の流れ（編集順）**。当日は下の【撮影順】で撮る（座りインタビューを先撮り→Bロールを後で重ねる）。

---

## A. 撮影前チェック（家に入る前・入った直後）

- [ ] **撮影許可／出演同意**：口頭で NG 範囲を確認＋簡易同意書（本番は Bグループが用意するか面談で確認）
- [ ] **個人情報の映り込み**：表札・住所・郵便物・家族写真・PC/スマホ画面・通知・窓の外の景色・近隣の生活音
- [ ] **音声**（最重要）：出演者にピンマイク（無ければ極力近接）／エアコン・冷蔵庫・換気扇を一旦 OFF／予備電池
- [ ] **画**：自然光が入る時間帯／三脚＋手持ちはジンバルか脇を締める／基本は横 16:9、サムネ用に数カット縦も
- [ ] **サムネ候補を最初に撮る**（部屋がきれいなうちに）：①立ち姿 ②収納オープン ③愛用品を手に ④"納得/驚き"の表情 ⑤物の少ない部屋の引き

## B. 当日の撮影順（※編集順とは別）

1. 到着 → 雑談 → 撮影 NG 確認
2. サムネ撮影
3. **座りインタビュー（価値観）を先撮り**
4. ルームツアー
5. 持ち物チェック
6. 締めコメント

→ 編集で、インタビュー音声の上に部屋・収納・持ち物の B ロールを重ねる。

---

## C. 完成動画 脚本（編集順）

### S1｜冒頭フック 0:00–0:30
- **映像**：一番"おっ"となる瞬間（収納をパッと開ける／驚きの一言）→ 物の少ない部屋の引き
- **MC（ナレ）**：「"物が増えない家"って、本当にあるんです。しかも理由は、間取りでも収納グッズでもなく——たった数個の"ルール"でした。」
- **〇〇（抜粋）**：「これ、もう3年買い足してないんですよ」
- **テロップ**：物が増えない家には、理由があった ／ 〇〇さん（△△歳・□□暮らし）
- **編集**：30秒以内・ベストカット3つ・BGM イン

### S2｜出演者紹介 0:30–1:30
- **映像**：玄関先で挨拶／プロフィールテロップ
- **MC**：「今日は〇〇さんのお宅にお邪魔します。まずは簡単に自己紹介をお願いできますか？」
- **〇〇（プロンプト）**：名前・年代・世帯・仕事・ミニマリスト歴・暮らしの一言
- **テロップ**：本日の訪問先 〇〇さん／キーワード3つ

### S3｜価値観の入口（なぜこの暮らしか）1:30–3:30
※座りインタビューの核を前半に置く（視聴維持の山を早く作る）
- **MC 質問**：
  1. 物を減らそうと思った"きっかけ"は何でしたか？
  2. 減らして一番変わったことは？（お金／時間／家事／気持ち）
  3. 〇〇さんにとって"ちょうどいい量"の基準は？
- **編集**：答えのハイライトのみ。深掘りは S7 に回す

### S4｜ルームツアー前半（玄関・キッチン・メインルーム）3:30–12:00
各場所で**必ず5問**：①ここは何の場所か ②何を置いているか ③なぜ増えないのか ④どんなルールか ⑤視聴者が真似できることは？

- **玄関**
  - MC：「まず玄関から。靴が…2足だけ？ なぜこれで足りるんですか？」→（5問を会話で）
  - 映像：靴箱オープン、たたきの引き、動線
  - テロップ：ルール①「1人〇足まで」
- **キッチン**
  - MC：「次はキッチン。調理器具、これだけで回るんですか？」→ 5問
  - 映像：シンク下／吊戸棚オープン、調理動線、よく使う道具
  - テロップ：ルール②「鍋は"1つで2役"」
- **メインルーム／リビング**
  - MC：「メインのお部屋へ。…床に物がない。どうやって維持してます？」→ 5問
  - 映像：部屋全体の引き、床、机まわり

### S5｜ルームツアー後半（収納・クローゼット・水回り）12:00–20:00
- **クローゼット**：MC「服の数、数えたことあります？」→ 5問／映像：ハンガー一覧、畳み方
  - テロップ：ルール③「ハンガーの本数＝服の上限」
- **収納（押入・引き出し）**：MC「"見えない収納"の中も見せてもらえますか？」→ 5問
- **洗面／トイレ／浴室・ランドリー**：MC「ストックは何個まで？」→ 5問／映像：洗面下、ストック棚
- **編集**：各場所の「ルール◯」をテロップで積み上げ、視聴者が"真似リスト"を作れるように

### S6｜持ち物チェック 20:00–28:00
机／床に愛用品を並べる。各アイテム**5問**：①いつから ②なぜ選んだ ③代わりに手放した物 ④失敗した買い物 ⑤今後も残す理由
- **定番セット**：財布・スマホ・鍵・バッグ・水筒・服1着・靴・ガジェット・充電器・毎日の日用品
- **MC 例**：「この財布、長く使ってますね。なぜこれを選んだ？ 逆に、手放した財布は？」
- **"あえて持たない物"**：MC「みんなが持ってるのに、〇〇さんが"持たない"と決めた物は？」
- **テロップ**：愛用品リスト（概要欄に対応）／"買わないルール"を1枚に

### S7｜価値観の深掘り 28:00–34:00（着地）
座りインタビューに戻る。
- **MC 質問**：
  1. 物を減らして、人生で一番変わったことは？
  2. 買う前に必ず自分に聞く"問い"はありますか？
  3. ご家族や周りの反応は？
  4. これからも残したい"暮らしの軸"を一言で。
  5. 同じように"物が多くて苦しい"視聴者へ、今日からできる一歩を。
- **編集**：BGM を少し上げ、今日の良い B ロールを被せる

### S8｜まとめ・CTA 34:00–
- **MC（ナレ）**：「〇〇さんの家にあったのは、特別な収納術じゃなくて、"買う前に一度止まる"という小さな習慣でした。あなたが今日から真似できそうなの、どれでしたか？ コメントで教えてください。」
- **テロップ**：今日の"真似できるルール"まとめ（3〜5個を再掲）／登録・次の動画
- **編集**：エンドカード、関連動画

## D. タイトル候補（物 → 価値観の型）
- 物が増えない家には、理由がありました。〇〇さんのミニマリスト宅
- 持ち物を見たら、その人の人生が見えてきた。〇〇さんの愛用品
- 〇〇を手放したら、暮らしがここまで変わった。

## E. サムネ
- 文字（2行・大）：「物が増えない家」「理由は"ルール"だった」
- 画：出演者＋収納オープン or 愛用品を手に。表情は"納得／驚き"。

## F. 2本分割にする場合（同日2本化が可なら）
- **1本目（ルームツアー）**＝ S1–S5 ＋ S8
- **2本目（持ち物・価値観）**＝ S1'（別フック）＋ S6 ＋ S7 ＋ S8'
- ※ 同日2本化の可否は Bグループに面談で確認。

## 次に詰めると撮影台本（香盤）まで落ちる
出演者（〇〇）確定で固有名詞・ルール名・愛用品を差し込み → 1本/2本・撮影者（単独/補助）・機材（ピンマイク/三脚）・編集環境（重い編集はしゅん先生PC）を決定。
