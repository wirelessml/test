# 引き継ぎ: 神戸市須磨区戎町限定の塾・教育系就職候補

## 方針

神戸市須磨区戎町限定で、塾・教育系の就職先を探す。

現時点では、戎町内または戎町3丁目の最有力候補は次の2つ。

## 第一候補: 武田塾 神戸板宿校

- 住所: 神戸市須磨区戎町3-1-24 豊ビル6階
- 職種: スクールマネージャー・教室長候補
- 求人詳細: https://www.miraiinc.jp/job/show/17
- 応募フォーム: https://www.miraiinc.jp/job/entry/17
- 優先度: 第一候補。応募フォームがあり、すぐ応募可能。

応募文の方向性:

```text
武田塾 神戸板宿校のスクールマネージャー・教室長候補に応募いたします。

「授業をしない塾」として、自学自習の計画・実行・確認を徹底管理する方針に強く関心があります。生徒一人ひとりの状況を見て、学習計画や面談、進捗管理を通じて合格まで伴走する仕事に携わりたいと考えています。

ご多忙のところ恐れ入りますが、何卒よろしくお願い申し上げます。
```

## 第二候補: 若松塾／株式会社聖文館

- 住所: 神戸市須磨区戎町3丁目1-23 聖文館ビル
- 若松塾板宿第二校: https://page.line.me/171hvckr
- 参考求人: https://doda.jp/DodaFront/View/CompanyJobs/j_id__10006681009/
- 優先度: 第二候補。戎町内の有力候補だが、公式応募導線が分かりにくい。

対応案:

- 正社員・教室運営スタッフ募集があるか問い合わせる。
- doda等の求人サイト経由で、板宿校・戎町勤務が可能か確認する。

## 結論

戎町限定なら、まず武田塾 神戸板宿校へ応募する。
並行して、若松塾／聖文館に正社員・教室運営スタッフの募集有無を確認する。
