# ミニマリスト宅訪問動画 制作打ち合わせメモ

作成日: 2026-06-06

## 目的

「動画スキル向上」ではなく、実際に1回の訪問でどんな動画を作るかを決めるための制作メモ。

想定は、ミニマリスト宅を訪問して、インタビュー、ルームツアー、持ち物紹介、価値観の深掘りを行うYouTube動画。

## 参考動画

### 参考1: ルームツアー型

- URL: https://youtu.be/K67hGIbdrII
- タイトル: `物が増えない、“超”仕組み化された家が衝撃だった。【minimalist_sho】`
- チャンネル: `ミニマリストsin / minimal chic life`
- 尺: 約41分
- 構成:
  - 00:00 オープニング
  - 00:37 玄関
  - 05:47 キッチン
  - 12:02 メインルーム
  - 23:01 トイレ&独立洗面台
  - 27:01 ランドリースペース&クローゼット
  - 31:57 モノを減らしたメリット&目的
  - 37:46 大事にしている暮らしの価値観
  - 40:51 エンディング

学ぶ点:

- 前半は場所別に家を見せる。
- 後半で「なぜその暮らしなのか」を聞く。
- 収納や動線の説明だけでなく、「増えない仕組み」に焦点を当てている。
- 視聴者は、部屋そのものより「真似できるルール」を見ている。

### 参考2: 持ち物チェック・価値観インタビュー型

- URL: https://youtu.be/_LGZCAB1JgA
- タイトル: `倹約ミニマリストと持ち物チェックしたら、大事な価値観が見えてきた ... ！`
- チャンネル: `ショウ / Z世代の持たない暮らし`
- 尺: 約28分
- 説明文の主旨: `持ち物を見れば、その人の人生がわかる。大切にしていること、価値観の違いを学ぶために minimalist_sin さんの持ち物と価値観を深掘り`

学ぶ点:

- 家全体ではなく、持ち物から人物を掘る企画。
- 愛用品リストを概要欄に載せられる。
- アフィリエイト/楽天ROOM/相談導線と相性がよい。
- 物の紹介だけで終わらず、「なぜそれを残したか」を聞く。

## 2本から見える制作の型

1回の訪問で、理想は2本分の素材を撮る。

1. ルームツアー動画
   - 家、収納、動線、仕組みを見せる
   - 視聴者の関心は「どうすれば物が増えないか」
2. 持ち物・価値観インタビュー動画
   - 愛用品、財布、バッグ、服、ガジェット、日用品を見せる
   - 視聴者の関心は「この人は何を大事にしているか」

Bグループ案件で1本15,000円の条件なら、同日2本化できるかは必ず確認する。採算評価ではなく、制作効率と経験値の問題として重要。

## 1回の訪問で撮るべき素材

### A. ルームツアー用

- 玄関
- キッチン
- メインルーム/リビング
- 寝室
- 洗面/トイレ/浴室まわり
- ランドリー
- クローゼット
- 収納の中
- 作業机
- 部屋全体の引き
- 生活動線が分かる移動カット

### B. 持ち物チェック用

- 財布
- スマホ
- バッグ
- 鍵
- 水筒
- 傘
- 服
- 靴
- ガジェット
- 充電器/ケーブル
- 毎日使う日用品
- あえて持っていない物
- 捨ててよかった物
- 残してよかった物

### C. 価値観インタビュー用

- 物を減らしたきっかけ
- 物が増えない仕組み
- 買う前のルール
- 捨てて一番変わったこと
- お金、時間、家事、気持ちの変化
- 家族や周囲との関係
- 今後も残したい暮らしの軸
- 視聴者が今日から真似できること

## 当日の撮影順

### 0. 到着直後

- まず雑談する。
- 撮影NGを確認する。
- 住所、郵便物、家族写真、PC画面、通知、表札、窓から見える景色に注意する。
- 家全体を見て、撮影順を決める。

### 1. サムネ候補を先に撮る

撮影の最後は疲れるので、部屋がきれいな最初に撮る。

- 出演者が部屋に立っている写真
- 収納を開けている写真
- 愛用品を手に持っている写真
- 驚き/納得の表情
- 物が少ない部屋全体の引き

### 2. 座りインタビュー

先に話を聞いて、あとでBロールを撮る。

理由:

- 何を見せるべきか分かる。
- 重要な物や場所が分かる。
- 編集時に話の上へ映像をかぶせやすい。

### 3. ルームツアー

場所順に歩く。

各場所で聞くこと:

1. ここは何の場所か
2. 何を置いているか
3. なぜ増えないのか
4. どんなルールがあるか
5. 視聴者が真似できることは何か

### 4. 持ち物チェック

机や床に愛用品を並べる。

各アイテムで聞くこと:

1. いつから使っているか
2. なぜこれを選んだか
3. 代わりに手放した物はあるか
4. 失敗した買い物はあるか
5. 今後も残す理由は何か

### 5. 締めコメント

- 今日の暮らしを一言で言うと何か
- 視聴者に一番伝えたいことは何か
- これからどんな暮らしにしたいか

## 完成動画の候補

### 案1: 1本完結版

- 尺: 25〜35分
- 内容: ルームツアー + 持ち物 + 価値観
- 向いている場面: 初回、1本納品しかできない場合

構成:

1. 冒頭ハイライト 0:00-0:30
2. 出演者紹介 0:30-1:30
3. 玄関/キッチン/メインルーム 1:30-12:00
4. 収納/クローゼット/水回り 12:00-20:00
5. 持ち物チェック 20:00-28:00
6. 物を減らした理由と価値観 28:00-34:00
7. まとめ 34:00-

### 案2: 2本分割版

1本目:

- タイトル例: `物が増えない家には理由があった。〇〇さんのミニマリスト宅を訪問`
- 内容: ルームツアー中心
- 尺: 25〜40分

2本目:

- タイトル例: `持ち物を見たら、その人の価値観が見えてきた。〇〇さんの愛用品チェック`
- 内容: 持ち物、買わないルール、人生観
- 尺: 15〜30分

利点:

- 1訪問で2本作れる。
- ルームツアー視聴者と持ち物紹介視聴者を分けられる。
- 概要欄で愛用品リンクやSNS導線を作りやすい。

## タイトルの方向性

参考動画のタイトルは、どちらも「物」から入って「価値観」に着地している。

使いやすい型:

- `物が増えない家には、理由がありました。`
- `持ち物を見たら、その人の人生が見えてきた。`
- `〇〇を手放したら、暮らしがここまで変わった。`
- `買わない人の家にあった、意外な仕組み。`
- `少ない物で暮らす人が、最後まで残した愛用品。`

## 撮影で一番大事なこと

部屋をきれいに撮るだけでは弱い。

重要なのは、各シーンで必ず次の3つを取ること。

1. 何があるか
2. なぜそうしているか
3. 視聴者が何を真似できるか

この3つが入ると、単なる部屋紹介ではなく、視聴者に残る動画になる。

## 次回打ち合わせで決めること

1. 最初に狙うのは1本完結版か、2本分割版か。
2. 出演者候補を誰にするか。
3. 撮影者は仲啓輔1人か、誰か補助がいるか。
4. iPhoneのみで行くか、外部マイク/三脚を用意するか。
5. 編集はどの環境で行うか。
