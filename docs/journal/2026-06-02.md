## 学んだこと / 気づき
1. **Codex CLI が WSL2 必須な理由**: モデル生成コマンドの OS サンドボックス（Linux=Landlock+seccomp / macOS=Seatbelt / Windows=非対応）。だから Windows では WSL2 が要る。Claude/Gemini は非依存なので Windows ネイティブで可。
2. **Codex Desktop App と CLI remote-control は app-server を奪い合う**（同一OS）。OS で役割を分ける（masup: CLI=WSL2 / Desktop=Windows）と両立。Mac は両方 macOS で競合 → どちらか一方。
3. **時刻は UTC/JST を必ず区別**。ログの `Z` は UTC。`21:21Z = 06:21 JST`。混同して「9時間沈黙」と誤判定 → ユーザー指摘で訂正。
4. **Cloudflare Turnstile は CDP/自動ブラウザを必ず弾く**。GUI フォーム送信は実OS入力（Codex Desktop の Computer Use 等）か手動が必要。
5. **WSL の gemini/antigravity は Windows-PATH interop**（`/mnt/c/...` 解決）。WSL から見えても Linux 側には無い。削除＝Windows側を消すことになるので注意。
6. **`pkill -f <pattern>` は自分のコマンドラインにも当たる**（`pkill -f 'openclaw/dist/index.js'` が自セッションを kill して処理中断）。広いパターンに注意。
7. **MASU-P55 WSL2 は RAM 3.7GB**: Whisper large-v3/medium は OOM/thrash。高精度文字起こしには不向き（small なら可だが今回は削除）。
