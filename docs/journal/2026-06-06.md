## 学んだこと / 運用知見

1. **`twitter` CLI の投稿は標準280字"加重"（日本語≒140字）が上限**。アカウントが Premium でも CLI 経由だと長文不可（エラー186）。**長文は本人が X app から手投稿**する必要あり。
2. **`twitter tweet <id>` がリプライIDで親(引用元/参照先)を誤返却するバグ**あり。本人投稿の実態確認は **`twitter search "from:user"`** が確実。
3. CLI の `isQuote` フラグは**返信(reply)を拾えない**（reply でも isQuote:False と出る）→ 単独/返信の判別は Chrome 実画面が確実。
4. **Chrome は read tier**＝スクリーンショットは可だが**クリック・スクロール・入力は不可**。確認は `open` で permalink 直打ち＋screenshot。
5. **permalink は親ツイートを描画しないことがある**。連結は「アバター上のスレッド線」か「親スレを開いて入れ子確認」で判定。
6. **大量返信のトークン最小化**＝一括ドラフト＋一括投稿＋**確認は最後に1回**。1件ずつ＋毎回スクショは桁違いに高い。
7. **有料note・センシティブ案件はペイウォール回避や海賊版探索をしない**（著作権・著者の目的を尊重）。無料部分＋二次情報で分析。
