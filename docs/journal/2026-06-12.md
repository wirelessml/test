## 学んだこと / 気づき

1. **bash は `$var` 直後にマルチバイト文字を置くと変数名を誤パースする**（`$now。` `$status（` で 2 連発）。`${var}` でブレース必須、または直後を ASCII にする。SessionStart フックと doctor の両方で踏んだ
2. **`codex exec` の stdout リダイレクトは実行ログ全部入り**（今回 289KB / 5,845 行、最終成果物は末尾 260 行）。次回は `--output-last-message <file>` の利用を検証するか、`grep -n` で最終セクションを切り出す
3. **macOS の `tar` は AppleDouble (`._*`) をアーカイブに混入させる**。他環境での監査・解析に出すと 58 件のノイズになる（`COPYFILE_DISABLE=1 tar ...` で抑止可）。サブエージェント検証の好例になった（Codex は知り得ない実環境情報）
4. **launchd の TCC 罠は「動いているから安全」ではない**（推測: TCC 評価はリブート等で変わる）。kioxia は 6/11 まで毎日成功 → 今朝のブート後 08:17 に突然 exit 126。事実ベースでは「Desktop 参照の LaunchAgent は時限爆弾」— doctor の TCC スキャンで雷管を事前検出できるようにした
5. **KeepAlive 常駐の port 競合は「孤児が生きて、管理側が死ぬ」形で現れる**。サービス自体は動いて見える（curl 応答あり）ので launchctl の exit 欄まで見ないと気づけない
6. **バイナリ成果物（docx）も中身をテキスト抽出してから着手する**。「TODO に未完と書いてあるから書く」だと 9,186 字の二重作業をするところだった。TODO リストより実体が真実
7. **`settings.local.json` の `Bash(*)`** が既設なので、この環境の permissions 整備は「プロンプト削減」ではなく「包括許可が消えた時に残る読み取り専用の床」と位置づけるのが正しい
8. Fable 5 の使いどころ実感: 横断検証（役割分担の三様矛盾の検出、5 スキル定義の不一致）と、複数系統の同時進行管理。消費でなく**設計時知能の固定化**に使うという朝の方針はワークした
