## 学んだこと / 気づき

### 1. SSH Session 0 isolation の workaround (再確認)

5/6 で codex が確立した **schtasks /IT 経由起動**手法は今日も再利用可能。`run-transcribe.bat` / `run-codex-remote.bat` どちらも schtasks で SSH session 切断に独立で動く。

### 2. 仲氏が裏で codex に依頼 = 並列作業の有効性

私 (Claude) がしゅん先生 PC で Python 3.13 segfault と格闘している間、 仲氏は codex に直接「文字起こし続きやって」と依頼 → codex は SSH 不通を即判断 → Mac で完成。私と codex の並列作業で全体時間短縮。

CLAUDE.md 5/6 引き継ぎ書のフロー (Claude Code → Codex 第一弾、 5/7 完全引き継ぎ書) が実運用で機能した好例。今日 codex は「私 (PID 2449) は触らず残す」 と協調的に動作。

### 3. Whisper の誤認識パターン

medium モデル + 日本語の固有名詞・専門用語で誤認識:
- **同音異義語**: 集団浅慮 → 集団占領、 損卓 → 忖度
- **数字**: 2024 → 2020 (「にじゅうよん」 → 「にじゅう」 で短縮)
- **希少姓**: 五百旗頭 (いおきべ) → 井沖部 (語彙にない、 large モデルなら通る可能性)
- **役職と苗字の組合せ**: 小橋 → 小林村、 井ノ本 → 稲本/井本

X tweet で他者の発信 (なごみさん) と cross-check することで訂正可能。

### 4. SuperWhisper のアプリ独自認証

iPhone Apple App Store の Pro Monthly サブスクは課金経路。アプリ内認証は **License Key + Email** の別経路。両方とも有効でないと Pro 機能解除されない。

`licenseValid` plist 強制書き込みで Pro 機能解放可能 = server reject なし (アプリ起動時にも plist 値を信じる)。ただし正式ルートは:
1. アプリ内で Email 入力
2. verification link メール受信 + クリック
3. アプリで sync 待ち

#### 「Lifetime」 vs「Monthly」 認識訂正

CLAUDE.md 4/29 ジャーナル「SuperWhisper Pro Lifetime」 記述は **誤記**。iPhone サブスク画面で「Pro Monthly、 5/28 まで」 と確認。5/28 を逃さないように reminders 化必要。

### 5. Codex 0.130.0 の新機能 `codex remote-control`

5/6 で Mac launchd 常駐させた app-server (localhost:18080、 WebSocket、 SSH tunnel 必要) とは別系統:
- `codex remote-control` 経由
- OpenAI cloud relay で iPhone App から直接接続
- Tailscale 不要、 ChatGPT Plus 認証
- Mac は Codex Desktop App が自動対応、 Windows は CLI で手動起動

Maki さんツイートで「Windows も対応か？」 と推測ベースで紹介されたが、 実機で確認 = Mac + Windows 両方 OK。 仲氏も 2 台で実証。

### 6. twitcasting 有料アーカイブの DL

Mac Brave で twitcasting ログイン後 (購入アカウント) + `--cookies-from-browser brave` で m3u8 取得可能。Windows Brave は DPAPI 復号失敗 (yt-dlp #10927) で取れず。**Mac は DPAPI ない = cookie 取得が圧倒的に楽**。

### 7. Python 3.13 + faster-whisper CT2 = ACCESS_VIOLATION

しゅん先生 PC で再現可能な segfault。GitHub issue にすると有用 (CT2 / faster-whisper の Python 3.13 完全対応待ち)。代替: **Python 3.11/3.12 にダウングレード**、 または **openai-whisper (pure Python)** 使用。

### 8. fxtwitter API の有用性

note_tweet (X 長文 tweet) の full text は通常 syndication API では truncated。**`api.fxtwitter.com/<user>/status/<id>`** で確実に full text 取得可能 (今日 Seowoo Han tweet で実証)。今後の X tweet 解析で常用。
