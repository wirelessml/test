## 学んだこと / 気づき

1. **ffmpeg avfoundation の画面キャプチャは現行 macOS でハングする**（音声デバイスは正常）。画面収録は `screencapture -x -v` が確実な代替。screenshot 実績があっても動画は別問題、と思いきや逆で、ffmpeg だけがダメだった
2. **avfoundation のデバイス番号は連係カメラ等で変動する**。番号指定は罠、**名前指定**（"Capture screen 0" / "MacBook Airのマイク"）に統一すべき
3. **whisper の繰り返しループ幻覚は `-mc 0` でほぼ解消**。面談録音系は最初から `-mc 0` を付ける
4. **2 音源 amix の録音は、後から片側だけ増幅できない**。面談録音は別トラック（または 2 ファイル）記録が正解（→ 改修 TODO）
5. **Zoom はアプリ無しでも Chrome の Web クライアントで実用十分**。カジュアル面談レベルなら brew インストール（sudo 必須）は不要
6. **求人応募 → 即カジュアル面談誘導 → LINE 誘導**は大量採用ファネルの型。LINE を断ってメールに切り替えるのは記録性の面でも正解
7. `brew install --cask zoom` は pkg インストーラが sudo を要求するため、**リモートセッション（非対話）からは入らない**
8. **🚨 M1 Mac は蓋を閉じるとマイクがハードウェアレベルで切断される**（カメラ同様のセキュリティ仕様、録音は -91dB のデジタル無音に）。**面談録画は必ず蓋を開けて行うこと**。`ioreg -r -k AppleClamshellState` で判定可
9. whisper は**先頭に長い無音がある音声でタイムスタンプを 0 に潰す**ことがある（連続会話ではほぼ正確）。会話マージの並びは近似と心得て、自分/相手の個別テキストを正とする
10. `ffmpeg -loglevel error` は **volumedetect の統計出力（info レベル）も殺す**。検量時は -loglevel を付けない
11. ffmpeg は **1 プロセスで 2 つの avfoundation 入力 → 2 つの WAV 出力**が可能（`-map 0:a out1 -map 1:a out2`）。別トラック録音はプロセス 1 本で済む
